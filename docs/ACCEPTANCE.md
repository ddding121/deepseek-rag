# 真实资料验收记录

在同一批资料和同一阈值下，对比仅语义、混合检索、混合加重排序。
准备 24 道真实问题：8 道直接事实、4 道型号/术语、4 道同义改写、4 道跨段问题、4 道资料无答案问题。
每题记录：完整问题、预期答案、原文件及页码/段落、检索是否命中、回答是否正确、引用是否支持答案、耗时。
无答案题应明确表示依据不足，不能以有引用或语言流畅作为正确标准。

## 必测操作

- 上传并提问，再重启，确认知识库仍在。
- 重复上传同一文件，确认跳过；新增文件只处理新增项。
- 替换同名文档后旧内容不再检索；删除后不再引用。
- OCR 识别结果与原图核对，特别是数字、单位和否定词。
- 最高语义分低于阈值时出现提醒；等于或高于时不出现。
- 下载备份，在另一个测试目录恢复并核对资料。
